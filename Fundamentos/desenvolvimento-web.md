# Curso 

## Cap. 3 - Diferença entre HTML, CSS e JavaScript 
- HTML e CSS não são linguagem de programação.
- HTML é uma linguagem de marcação.
- CSS é uma linguagem de folhas de estilo.
- A HTML - Hyper Text Markup Language - Quando você clica em uma área e é direcionada para outra.
- As CSS - Cascading Styke Sheets - Porque vão modificando uma característica uma na outra.

- HTML é focada em conteúdo - Texto, imagem, vídeo, tabelas.
- CSS é focada em design - Cores, sombras, tamanho, posicionamento
- JavaScript - É uma linguagem - focada em interações - Menu interativo, animações, validações
- Os 3 são conjuntinho
- Estrutura básica de documento HTML (Ver pasta)

## Cap 3 - Front-end, Back-end e Full Stack
- Front-end (Tecnologias Client Side) - HTML, CSS, JS - não funcionam no servidor
- Back-end (Server side) - linguagens PHP, JS node, Phyton, c#, Ruby, Java 
- Full stack - Soma de ambos
